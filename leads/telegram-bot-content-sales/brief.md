# Лид: Telegram-бот под ключ (контент + продажи)

Источник: кворк «Создам Telegram бота под ключ за 2 дня: заявки, касса, админка»

## Что нужно клиенту

Автоматизация цикла: производство контента → дистрибуция → аудитория через Telegram-бот → монетизация → аналитика.

### 1. Производство
- Notion: карточка эпизода (статус «Идея») по добавлению темы
- Descript / AI: расшифровка аудио
- ChatGPT: генерация постов (TG, VK, Дзен), чек-листов
- Canva: оформление PDF-бонусов

### 2. Дистрибуция
- Podster + RSS → площадки
- RSS → Telegram-канал (Zapier / n8n)
- VK: SMM-планнер / VK Админка
- Дзен: пока вручную

### 3. Telegram-бот (ядро)
- /start + меню с кнопками
- Раздача PDF-бонусов
- Квизы (5 вопросов → результат)
- Сбор контактов → Google Sheets
- Подписка на закрытый канал (VK Donut → инвайт)
- Магазин мини-гайдов (VK Pay → выдача файла)
- Регистрация на марафоны
- Продажа сессий игры (оплата → Zoom-ссылка)

### 4. Оплата
- VK Pay или Telegram Stars

### 5. Админка
- Управление контентом (PDF, гайды, квизы, рассылки)
- Просмотр базы подписчиков и продаж

## Стек (предложение)
- Python (aiogram 3) — бот
- FastAPI — вебхуки оплат, админка API
- PostgreSQL / SQLite — база
- Google Sheets API — зеркало базы
- Простая веб-админка (React/Vue или Django admin)
- Хостинг: VPS (Docker) или Railway/Render

## Открытые вопросы клиенту
1. VK Pay или Telegram Stars как основной? (VK Pay = комиссии, юр. лицо; Stars = проще)
2. Закрытый канал в Telegram или VK Donut? (в задаче упомянут VK Donut, но выдача — TG-инвайт — нужна связка)
3. Есть ли Notion API токен и готовый шаблон карточки?
4. Zoom — Pro/Business аккаунт? Нужен API-доступ.
5. Сколько типов PDF/квизов на старте?
6. Нужна ли админка как отдельный веб-интерфейс или достаточно управления через бота?
7. Хостинг: свой VPS или подобрать?

## Оценка
- Срок «2 дня» — маркетинг; реальный MVP ~7–10 дней, полный функционал 3–4 недели
- Бюджет — уточнить у клиента
