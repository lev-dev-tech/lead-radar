**По ядру — Telegram-боту:**
- Пишу на Python (aiogram 3) + PostgreSQL. Кнопочные меню, сценарии, состояния — стандарт.
- Раздача PDF, квизы с подсчётом результата, сбор контактов в Google Sheets (через service account) — базовый функционал.
- Приём оплаты: и Telegram Stars, и VK Pay — рабочие варианты. Stars проще и без юр. лица, VK Pay нужен при продаже через VK Товары. Могу подключить оба.
- Автовыдача PDF и ссылок (Zoom, инвайты в закрытый канал) — по событию оплаты через вебхук.
- Подписка на закрытый TG-канал после оплаты VK Donut — реализуется через проверку статуса донов + генерация одноразовых invite-ссылок.

**По контент-циклу:**
- Notion → карточка при добавлении темы: через Notion API, автоматически.
- Расшифровка аудио: Whisper API (дешевле и качественнее Descript для русского), либо оставим Descript, если у вас уже подписка.
- Генерация постов и чек-листов: OpenAI API с вашими промптами, сохранение в Notion/Sheets на модерацию.
- Публикация в TG-канал по RSS с Podster — через n8n (надёжнее Zapier и без лимитов).
- VK — через API сообщества, отложенные посты по расписанию.

**Админка:**
- Лёгкая веб-панель: управление PDF/гайдами, квизами, рассылками, просмотр базы подписчиков и продаж. Либо, если хочется совсем минимализма, — управление через самого бота (команды владельца).
