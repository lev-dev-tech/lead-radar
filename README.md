# Радар лидов (parser + lead_radar)

Автоматический подбор фриланс-заказов из Telegram под стек: боты, mini app,
GetCourse, CRM/Bitrix, парсеры, вебинары, сайты. Собирает заказы из папки Telegram,
отбирает подходящие, готовит отклик под каждый и выводит в приложение `Лиды.html`.

## Состав
- `parser.py` — читает каналы из папки Telegram, отбирает вакансии, пишет `вакансии_техспец.xlsx`.
- `lead_radar.py` — фильтрует клиентские заказы, пишет отклики, генерирует `Лиды.html` (вкладки «Заказы» и «Ответы»).
- `inbox.py` — читает входящие ЛС (вкладка «Ответы»).
- `notify.py` — шлёт напоминание в Telegram со второго аккаунта на основной.
- `login_lev.py` — вход в основной аккаунт по QR-коду.
- `config.py` — настройки (без секретов). Секреты — в `credentials.py`.

## Установка
1. `python -m venv .venv` и активировать.
2. `pip install -r requirements.txt` (+ `pip install anthropic` для AI-режима).
3. Скопировать `credentials.example.py` → `credentials.py`, вписать api_id/api_hash.
4. Войти в аккаунт: `python login_lev.py` (скан QR телефоном).
5. Запуск: `python lead_radar.py` — обновит заказы и соберёт `Лиды.html`.

## Автозапуск (Windows)
Планировщик: `LeadRadar` (парсинг каждые 3 ч), `LeadReminder` (напоминание за 10 мин).

## Безопасность
`credentials.py` и `*.session` — это доступ к Telegram-аккаунту. Они в `.gitignore`
и НИКОГДА не должны попадать в репозиторий или на публичный сервер.
